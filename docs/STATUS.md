# 首版验证记录

日期：2026-10-28。版本状态：实验性源码首版。

## 已完成

- 281 项 Python/C 离线测试通过：失败、错误、跳过和预期失败均为 0。
- Go TLS 桥的 7 组测试通过，并启用 race 检查：证书、WebSocket 转发、本机/上游令牌隔离、路由、配置权限和 SNTP 响应边界。
- 客户端、面板和 TLS 桥真实交叉编译为目标 ARM 架构，校验旧 glibc ABI 和动态符号。
- 用用户自备的匹配原厂模板及合成配置完成镜像重组：8,110,080 字节，小于 8 MiB；内核、DTB、其余头字段与原非 init CPIO 成员保持不变。
- 公开树检查通过：不含家庭设备身份、私有平台地址、账号令牌、录音、原厂库、模型或固件镜像。
- 内嵌提示音可从原创整数波形配方重新生成一致内容。

## 尚未完成

- 新通用版本没有重新在真实音箱上启动和听测。
- 没有针对任意小智托管服务完成注册、激活和全流程对话验收。
- 没有面向任意主板的一键安装器、健康确认和通用 OTA 发布流程。
- 没有声纹识别，也不保证极短弱语音、远场收音或播放时打断达到原厂效果。

验证过程中没有连接、升级或启动当前家用音箱的麦克风；家用音箱保持原厂系统。上述离线通过结果不能替代安装前的设备适配、备份和真实声学测试。
