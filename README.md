# 小爱 S12 → 小智

将第一代小米 AI 音箱（S12/S12A，白色长方柱形）改为小智 WebSocket 语音终端的社区项目。

设备直接连接你选择的小智兼容服务，**不需要项目作者的云服务、账号、设备注册库或发布平台**。它运行在音箱原有 ARM Linux 主板上，不是给 ESP32 刷写的固件。

**状态：实验性源码首版。** 硬件适配来自真实 S12A 改造；本仓库重新整理后的通用连接和启动镜像尚未做独立实机验收。当前提供源码、离线测试和本地构建工具，不发布包含个人配置或小米闭源组件的通用刷机包。

## 功能与边界

| 项目 | 当前情况 |
| --- | --- |
| 小智接入 | WebSocket v1，JSON 控制消息、Opus 音频；可配置 `wss://` 服务或内网 `ws://` 服务 |
| 本地唤醒 | 使用用户自备原厂只读系统中的“小爱同学”唤醒库和模型；待机音频不上传 |
| 麦克风 | S12A 六麦输入、原厂前端适配和健康度选择；不保证所有声学环境下的远场效果 |
| 喇叭、触摸环、静音、灯环 | 设备端适配源码；静音状态由设备端控制 |
| 提示音 | 本仓库使用可复现的原创合成短音，不分发原厂音频或旧 TTS 缓存 |
| 语音识别 / 大模型 / TTS | 由用户选择的小智服务提供；设备本身没有通用离线 ASR 或离线神经 TTS |
| 音量工具 | 标准语音连接上的 MCP；服务端需支持设备工具 |
| 连续对话、音乐队列 | 依赖服务端能力；私有协议扩展不作为通用小智能力保证 |
| 播放时唤醒打断 | 保留客户端实现；回声参考须在目标硬件验证，不默认声称原厂同等效果 |
| 激活、OTA | 不依赖作者平台；首版手动配置服务端地址/凭据，本地构建，不附自动刷机入口 |

本项目的原创代码采用 MIT，第三方源码保留各自许可证。**小米内核、DTB、驱动、唤醒库、模型和系统库不随仓库分发**，需要从你自己持有的匹配固件或设备取得。见 [开源范围](docs/OPEN_SOURCE_SCOPE.md) 与 [第三方声明](THIRD_PARTY_NOTICES.md)。

## 工作方式

```text
六麦 / 本地唤醒 / 触摸与灯环
             ↓
       S12A 原生 C 客户端
             ↓ 本机鉴权，仅 loopback
       通用 WebSocket TLS 桥
             ↓ 直接连接用户配置的服务器
       小智兼容 ASR / LLM / TTS
```

TLS 桥与客户端运行在同一台音箱，只转发协议，不运行云端推理，不保存对话。它使用证书校验，将本机令牌与上游凭据分开，避免把本机令牌发给远端服务。

## 开始

需要 Python 3.10+、Go 1.22+、Zig 0.13.0，以及用户自备的 S12A 原厂 1.76.54 `boot.img` 和只读系统库。普通电脑上的离线测试不需要原厂固件；C 模拟测试需要 clang、Opus 和 json-c 开发包。

```sh
# Linux 上安装 C 测试依赖：
# sudo apt install clang pkg-config libopus-dev libjson-c-dev
# macOS：brew install opus json-c pkgconf

make test

# 准备自己的服务与 Wi-Fi 配置。密码与令牌交互输入，不放命令行。
python3 scripts/prepare_config.py --help

# 用户自备工具链、原厂系统库：
python3 scripts/build.py --help
python3 scripts/build_image.py --help
```

构建、配置格式和镜像校验步骤见 [构建说明](docs/BUILD.md)。协议兼容范围见 [协议说明](docs/PROTOCOL.md)。

## 安装与恢复

**先看 [安装与恢复边界](docs/RECOVERY.md)。** 构建工具只在电脑上生成镜像，不扫描音箱、不连接串口、不改启动环境、不写 NAND。首次适配应通过已验证的 RAM 启动流程测试，再考虑仅安装到备用 `boot1`。不要覆盖原厂 `boot0`、`system0`、Bootloader、密钥区或整颗 NAND。

串口引脚必须由实际主板测量确认，不能仅凭另一台音箱的照片照接。ESP32-S3 在一些改造方案中只是 3.3V 串口桥；本项目不需要操作家中的其它 ESP32 设备。

## 发布与贡献

发布前运行 `make public-check`。不要提交个人配置、原厂库、模型、录音、成品镜像或历史私有工程。修改设备协议时补充模拟服务器回归；改变音频或启动流程后，在真实目标设备上验收并记录条件。见 [发布清单](docs/RELEASE_CHECKLIST.md)。

小智协议参考：[xiaozhi-esp32 WebSocket 文档](https://github.com/78/xiaozhi-esp32/blob/main/docs/websocket.md)。本项目是独立的社区适配，与小米及小智官方没有隶属关系。
